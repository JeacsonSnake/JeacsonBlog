# 机器数与 IEEE-754

## 核心结论

> 能在二进制下被**完美表示**（没有无限循环小数位）的数，称为**机器数**。IEEE-754 用「符号位 + 偏移指数 + 尾数」三段把浮点数塞进固定位宽：单精度 32 位（bias 127）、双精度 64 位（bias 1023）。理解机器数的价值在于：**计算机里所有小数运算的误差、溢出、比较失败，都源于这个表示法本身的离散性。**

## 一、机器数

一个十进制数转成机器能识别的二进制数时，若能被完美表示为二进制而不存在无限不循环小数位，这个数就是**机器数**。

$$
x = m \times 2^{e},\quad 1 \le m < 2
$$

把尾数的小数点放在第一位与第二位之间、并保证首位非 0，这个处理叫**规范化（normalized）**。

## 二、IEEE-754 的三种形式

IEEE 754 规定了四种表示方式：单精度（32 位）、双精度（64 位）、延伸单精度（43 位以上，很少用）、延伸双精度（79 位以上，通常 80 位实现）。本项目用到前两种：

| | 符号位 s | 指数位 e′ | 尾数 m | 偏移量 bias |
|---|---|---|---|---|
| 单精度 SP | 1 位 | 8 位 | 23 位 | **127** |
| 双精度 DP | 1 位 | 11 位 | 52 位 | **1023** |

- **符号位**：0 正 1 负；
- **偏移指数 e′**：以 2 为底的指数加上 bias 后的无符号数；
- **尾数 m**：规范化后小数点右侧的位（整数部分的 1 被隐式省略，即「隐藏位」）。

## 三、十进制 → 机器数（小数值）

以 20.5 为例：

1. 转二进制：$(20.5)_{10} = (10100.1)_2$
2. 规范化：$10100.1 = 1.01001 \times 2^{4}$ → 尾数 `01001`，未偏移指数 e = 4
3. 加偏移：$e' = e + b = 4 + 127 = 131 = (1000\ 0011)_2$
4. 尾数补足 23 位：`0100 1000 0000 0000 000`
5. 组装（正数 s = 0）：

```text
0 10000011 01001000000000000000000  =  0x41A40000
```

## 四、十进制 → 机器数（大数）

对 $-4.96633978947244 \times 10^{22}$ 这类数，直接展开不现实，用「数量级估算」：

1. 符号为负 → s = 1；
2. 取绝对值，把 $10^{22}$ 换成二进制量级：因 $10^3 \approx 2^{10}$，故 $10^{22} \approx 2^{70}$；
3. $4.966 \times 10^{22} \approx a \times 2^{70}$ → $a \approx 42.07 = 1.3146 \times 2^{5}$；
4. 于是 $e = 70 + 5 = 75$，$e' = 75 + 127 = 202 = (1100\ 1010)_2$；
5. 把 $0.3146$ 转二进制得 24 位，按舍入规则截到 23 位；

```text
1 11001010 01010000100010000100010  =  0xE5284422
```

> 估算次方数时的反直觉之处：**次方数估得越"精确"反而误差越大**，先取整到几十次方即可。

## 五、机器数 → 十进制

例：SP 机器数 `0xD1500000`

```text
0xD1500000 = 1101 0001 0101 0000 … 0000
s = 1
e' = 2^7 + 2^5 + 2^1 = 162  →  e = e' - 127 = 35
m = 1.1010 0000 …（含隐藏位）
value = (-1)^s × 1.625 × 2^35 = -1.625 × 2^35 ≈ -5.583 × 10^10
```

通用公式：

$$
\text{value} = (-1)^{s} \times (1.m)_2 \times 2^{(e' - b)}
$$

## 六、特殊值与数值范围

当 $e'$ 全 0 或全 1 时，编码用于表示特殊值：**±0、±∞、NaN**（以及非规格化数）。因此正常数的指数范围是 $1 \le e' \le 254$（SP）/ $1 \le e' \le 2046$（DP）。

| | 最大机器数值 | 最小机器数值 |
|---|---|---|
| 单精度 | $\pm 3.4 \times 10^{38}$ | $\pm 1.2 \times 10^{-38}$ |
| 双精度 | $\pm 1.8 \times 10^{308}$ | $\pm 2.2 \times 10^{-308}$ |

- **溢出（Overflow）**：绝对值 > 最大值（如单精度 $> 3.4\times10^{38}$）；
- **下溢（Underflow）**：绝对值 < 最小值（如单精度 $< 1.2\times10^{-38}$）。

## 七、上一位 / 下一位与机器精度

相邻两个机器数之间的距离由**尾数最低位**（$2^{-23}$）与指数共同决定：

$$
\text{下一位} = x + 2^{e} \times 2^{-23},\qquad
\text{上一位} = x - 2^{e} \times 2^{-23}
$$

对 20.5（e = 4）：

```text
下一位 = 20.5 + 2^4 × 2^-23 = 20.5000019073486328125
上一位 = 20.5 - 2^4 × 2^-23 = 20.4999980926513671875
```

**机器精度** $\epsilon_{mach}$ 定义为该精度下「1 与下一个机器数之间的距离」：

$$
\epsilon_{mach} = (1 + 2^{-23}) - 1 = 2^{-23} \approx 1.19 \times 10^{-7}
$$

一般规律：$\epsilon_{mach}$ = 2 的「尾数最后一位所代表的二进制位数」次方。

## 八、误差与舍入

任何落在「本位数 ± 半个间隔」之间的实数，都会被**估计为最近的机器数**（四舍六入五成双的邻域思想）。由此产生：

$$
\text{真误差} = |\text{真实值} - \text{估计值}|
$$

$$
\text{真实相对误差} = \left|\frac{\text{真实值} - \text{估计值}}{\text{真实值}}\right| \times 100\%
$$

例：20.4999991 与 20.5 的真误差 0.0000009，真实相对误差 ≈ 0.00000439%。

**舍入规则**：把小数位限制在尾数位内，对紧接着的那一位（MSB）判定 ——

- MSB 为 0：剩余全部舍去（截断）；
- MSB 为 1：尾数末位加一。

例：$(9.4)_{10} = (1001.\overline{0110})_2 = 1.001\overline{0110} \times 2^{3}$ → s = 0、$e' = 3 + 127 = 130$、尾数取 `0010 1100 1100 1100 110`，其后为 `01`，MSB = 0 → 直接舍去。

## 九、工程含义

- 浮点数**不满足结合律**：$(a+b)+c \ne a+(b+c)$，累加大量小数时要用 Kahan 求和或高精度中间量；
- **不要用 `==` 比较浮点**，用 $\epsilon$ 容差；
- 0.1 + 0.2 ≠ 0.3 的根因就在这里：0.1 在二进制下是无限循环小数，存进机器数时已被舍入；
- 相对误差随数值量级变化，而**绝对误差**随指数增长 —— 大数运算更容易丢失低位有效信息。
