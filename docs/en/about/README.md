🎹 My undergraduate final-year project was set against the backdrop of the industrial application of a simple musical staff recognition model, utilising the lightweight neural network MobileNetV3 to develop a piano-playing robot based on a Raspberry Pi. This project comprised components such as image capture, data processing and hardware control. It recognises simple musical notation using an external camera to play the piano. Both the music notation recognition programme and the hardware control programme based on the recognition results were developed using the Python programming language. By controlling a high-level signal to trigger a relay, which in turn operates a push-pull solenoid, the robot is able to play the piano keyboard. You can view my archived video from that time (in English) via [this LinkedIn page](https://www.linkedin.com/feed/update/urn:li:activity:7503320366174347264/).
