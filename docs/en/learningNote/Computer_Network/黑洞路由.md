A blackhole route is also a static route, but what makes it different from other routes is that a blackhole route's outgoing interface is NULL0. If a static route's outgoing interface is NULL0, we call that route a blackhole route.

Put simply, if the outgoing interface of a static route's network segment is specified as NULL0, then every data packet headed for that segment is dropped outright, with no forwarding.
