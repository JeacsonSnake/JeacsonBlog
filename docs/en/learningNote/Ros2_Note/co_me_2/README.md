## Brief

These are my notes on the supplementary material for ROS2 communication mechanisms. Compared with the [core material](../co_me/README.md), the knowledge density here is looser, and it covers:

- Setting up a distributed framework (getting different ROS2 devices talking to each other)
- Dealing with name clashes (clashing custom packages, nodes, and topics inside a node)
- Commonly used APIs (time APIs such as timers)
- Communication-mechanism tools (further explanation of the relevant commands, the rqt toolbox, and so on)

For details on the hardware, software and technical background, see [A Brief Introduction to the ROS2 Notes Collection](../README.md)
