## 📄 arXiv Papers — cs.AI / cs.LG / cs.CL
*(The 5 papers most relevant to agents / reasoning / LLM training / inference)*

- **[ArchSpace: Recording, Reviewing, and Referencing LLM Architecture Research](https://arxiv.org/abs/2611.17332)** | cs.CL | Jie Wang, Tong Zhu
  *A record–reproduce–cite platform for LLM architecture research. The authors note that teams such as DeepSeek, Qwen and Kimi keep pushing architectural innovation, yet experimental details are hard to reproduce and hard to compare, so a structured carrier for architecture research is needed.*
- **[AgentSSL: Can MLE Agents Leverage Unlabeled Data?](https://arxiv.org/abs/2611.17323)** | cs.AI | Ethan Lin, Akanksha Sarkar
  *Asks whether automated machine-learning engineering (MLE) agents can exploit unlabeled data the way human engineers do. Such agents have so far been evaluated almost exclusively in fully supervised settings.*
- **[CoReMem: Cost-Internalizing Memory for Successive Coding Tasks with Prospective Valuation](https://arxiv.org/abs/2611.17316)** | cs.AI | Peiwen Li, Harshit Verma
  *A memory mechanism for "successive coding tasks": the agent must decide what memory to write before it knows what the next task is. The method folds the cost of writing and reading memory into that choice.*
- **[Learning When Diffusion Language Models Should Regenerate](https://arxiv.org/abs/2611.17320)** | cs.CL | Minhae Oh, Jeonghye Kim
  *Diffusion language models can put generated content back through the mill and rewrite it, but the hard part is deciding when, and which span, to change. On Sudoku the authors find that hidden states carry error information which token confidence fails to reflect.*
- **[Classical Energies Learn to Reason 1,000x Faster than Looped Models](https://arxiv.org/abs/2611.17309)** | cs.AI | Benjamin Hoover, Hugh Blayney
  *Uses classical energy models for reasoning; on Sudoku and maze tasks it runs about three orders of magnitude faster than looped models, with more stable training and lower parameter and compute overhead.*
