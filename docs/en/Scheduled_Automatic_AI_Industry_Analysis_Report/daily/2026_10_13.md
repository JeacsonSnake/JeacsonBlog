## 📄 arXiv Papers — cs.AI / cs.LG / cs.CL

- **[Can Language Models Play the Wikipedia Game?](https://arxiv.org/abs/2610.13948)** | cs.AI | Alexander Hickey, Joanna Knight
  *Tests LLMs' information-retrieval/navigation ability through the "Wikipedia game" (reaching a target entry using only article links). Across 5 languages + 5 academic-literature datasets, no model significantly beats humans, though GPT-o3 mini, GPT-4o, QwQ:32B and DeepSeek-R1:70B perform on par with humans.*
- **[RATED: Reliability-Aware AI Agent Tool Retrieval via Execution Dynamics](https://arxiv.org/abs/2610.13889)** | cs.AI | Weiliang Chen, Song Liao
  *Targets the problem that agent tool retrieval "looks only at semantic relevance and ignores runtime availability", re-ranking with a dual encoder + contextual bandit driven by real execution feedback. On real queries MRR rises 52.2% over ToolLLM; under severe API failure (30% failure rate) the wrong-selection rate drops from 86.2% to 2.9%, with < 1ms latency overhead.*
- **[X-AgentRed: Red-Teaming Personal Agents in Evolving Multi-Service Ecosystems](https://arxiv.org/abs/2610.13886)** | cs.AI | Yeonsung Jung, Zhiyuan Wang
  *Personal agents calling tools across services produce compositional harms. This method uses a self-evolving red-teaming framework that mines harmful call paths from a tool-dependency graph + execution feedback, reaching 1.77x the harmful-path rate and 2.99x the tool coverage of STAC on 4 frontier agent models.*
- **[Task Context Shapes Component Roles in Language Models](https://arxiv.org/abs/2610.13895)** | cs.CL | Sovesh Mohapatra, Dani S Bassett
  *Comparing fixed model components on the same set of graph facts across tasks, task changes reassign the influence of attention heads — shared components read different facts and affect downstream computation differently depending on the task (measured on Gemma-2-9B / Qwen3-14B).*
- **[MC-EvoBench: Auditing Experience-Driven Self-Improvement in Minecraft Agents](https://arxiv.org/abs/2610.13829)** | cs.RO | Jingwei Song, Zhisheng Chen
  *A controllable benchmark for "embodied recursive self-improvement": 19 evolution chains, paired probes, allowing only declared agent artifacts to cross the source-target boundary. The conclusion is that the relevant experience did not bring stable transfer — early collection/synthesis bottlenecks often make later capabilities unobservable at all.*
