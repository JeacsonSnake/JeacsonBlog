## 📄 arXiv Papers — cs.AI / cs.LG / cs.CL
*(5 papers most relevant to agents / reasoning / LLM training / inference)*

- **[Delegent: A Multi-Agent Harness That Reduces Cost without Sacrificing Performance](https://arxiv.org/abs/2611.33098)** | cs.AI | Lingwei Gu, Jimmy Lin
  A frontier model leads the task and hands simple subtasks such as code lookup, test runs and retrieval to local SLM subagents; a 27B FP8 SLM cuts long-horizon coding cost by 67% and agentic search by 59%, and a 2B model still cuts 66%, with no loss in performance. Code is open-sourced.
- **[CoT-Proxy: Cross-Format Transfer for Distilling Long-Horizon Policies](https://arxiv.org/abs/2611.33148)** | cs.CL | Dawid J. Kopiczko, Tijmen Blankevoort, Yuki M. Asano
  Distills long-horizon agent policies using only the teacher model's action trajectories (without hidden CoT); after training with empty reasoning blocks, thinking at inference time still transfers; Qwen3-4B rises from 7% to 18% on AppWorld, to 35% with CoT-proxy, and reaches 48% using GPT-5.6 Luna's visible outputs.
- **[Reinforcement Learning Can Be Recovered From Its Own Rollouts](https://arxiv.org/abs/2611.33102)** | cs.LG | Jiayi Sheng, Jingwen Gu, Guanning Zeng
  Much of the knowledge from RL post-training stays in the rollouts: maximum likelihood on archived trajectories in generation order (regardless of correctness) reproduces online RL performance, suggesting RL compute is largely spent on "discovering a better sampling distribution".
- **[A Bias in Disguise: Tiny Gradient Edits Stop a Small Language Model's Thinking Loops and Complement a Frontier Model's Weight Edit](https://arxiv.org/abs/2611.33133)** | cs.LG | Hussamuddin Syed
  Qwen3.5-0.8B's thinking mode often fails to converge; fine-tuning only the roughly 140k weights with the largest gradients lifts MATH-500 from 15.4% to 39–45.5% under a 4k token budget, and reaches 62.2% when combined with gradient-free weight editing of GPT-6 Astra.
- **[Draft Calibration for Speculative Decoding: Accelerating LLM Serving by Matching Draft and Target Distributions](https://arxiv.org/abs/2611.33111)** | cs.LG | Yuxing Liu, Wei Zuo, Walid Krichene
  Open-source draft models are generally underconfident relative to their target models; temperature-scaling the draft distribution raises speculative decoding's accepted length by about 10% at almost zero cost.
