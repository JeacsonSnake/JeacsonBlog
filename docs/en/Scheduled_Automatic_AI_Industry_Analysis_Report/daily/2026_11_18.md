*(The 5 papers most relevant to agents / reasoning / LLM training / inference)*

- **[Latent Lattice Language Models](https://arxiv.org/abs/2611.21608)** | cs.LG | Shivam Duggal, Zongze Wu, William T. Freeman
  *Rather than the old route of "deeper / recurrent layers", it uses a latent lattice residual structure to raise compute per token — exploring another axis for scaling language models.*
- **[ViRA: Toward Ultra-High-Resolution Visual Agents via Cross-Input Relative Policy Optimization](https://arxiv.org/abs/2611.21605)** | cs.CV | Huawei Lin, Jinting Liu, Tongyan Wang
  *A visual agent for ultra-high-resolution images, using cross-input relative policy optimization for RL to force the model to actually zoom in and read the evidence instead of guessing from common sense.*
- **[Mitigating Catastrophic Forgetting with Physics-Indexed Specialist Memory: the Evolutionary Neuroplastic Agent](https://arxiv.org/abs/2611.21598)** | cs.LG | Blas Eugenio Vicco Zarate, Miguel Hernán Vicco
  *Uses "specialists" produced by evolutionary search as reusable memory, helping continual RL keep old abilities when the environment changes.*
- **[When Tool Names Are Not Identities: Measuring Provider Misbinding in MCP-Based AI Agents](https://arxiv.org/abs/2611.21577)** | cs.CR | Zeynab Anbiaee, Sajjad Dadkhah, Ali A. Ghorbani
  *Systematically measures "provider misbinding" in multi-server MCP setups: tools with the same name get attributed to the wrong provider, and the agent may send sensitive calls to the wrong service.*
- **[Reading or Remembering? Measuring Temporal Contamination in Language Models](https://arxiv.org/abs/2611.21554)** | cs.LG | Arunkumar V, Gangadharan G. R., S. Senthilkumar
  *Quantifies temporal contamination with a central-bank text prediction task — reading a 2021 statement, the model may already "remember" the 2022 outcome, inflating evaluation scores.*
