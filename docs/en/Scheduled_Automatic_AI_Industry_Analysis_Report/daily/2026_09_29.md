## 📄 arXiv Papers — cs.AI / cs.LG / cs.CL
*(5 papers most relevant to agents / reasoning / LLM training & inference)*

> Note: the latest submission date in the arXiv index was **09/25**; the papers below are the newest available at that point, not strictly 24h content.

1. **[Learning to Stop without Learning to Stop: Self-Supervised Confidence Training Improves Reasoning Efficiency](https://arxiv.org/abs/2609.31619)** | cs.AI | Parsa Hosseini, Akasha Tigalappanavara
   Reasoning models generate overlong chains of thought with huge inference cost; existing approaches mostly do early stopping at inference time, whereas this paper uses self-supervised confidence training to let the model learn when to stop.
2. **[New LoRA Skills Should Read but Never Write](https://arxiv.org/abs/2609.31600)** | cs.LG | Zeyan Li, Panqi Yang
   LoRA makes single-task fine-tuning cheap, but merging multiple independently trained adapters into the same model remains hard — the paper proposes "new skills read-only, never write" for merge conflicts.
3. **[Compact Documentation for Coding Agents: A Benchmark, an Optimizer, and Why It Does Not Transfer](https://arxiv.org/abs/2609.31587)** | cs.SE | Md Shohel Arman, Igor Molybog
   Systematically tests whether natural-language docs really help coding agents locate and fix software problems, providing a roundtrip benchmark for building and evaluating docs (conclusion: the benefit doesn't transfer easily).
4. **[Multi-agent Scaling Across Disjunctive and Compensatory Tasks](https://arxiv.org/abs/2609.31563)** | cs.AI | Carolina Fortuna, Blaz Bertalanic
   Multi-agent LLM systems aren't better just because the team is bigger; the paper characterizes the boundary of scaling gains by task structure (decomposable vs. compensatory).
5. **[EAServe: Encode-Aware Disaggregated Serving for Multimodal Large Language Models](https://arxiv.org/abs/2609.31551)** | cs.DC | Kunxiong Zhu, Zhihao Shu
   Prefill/Decode disaggregated deployment is already standard for LLM serving, but multimodality adds an Encode stage; this paper proposes an encode-stage-aware disaggregated serving scheme.
