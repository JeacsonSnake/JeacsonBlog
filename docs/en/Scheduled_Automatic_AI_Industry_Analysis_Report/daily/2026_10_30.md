## 📄 arXiv Papers — cs.AI / cs.LG / cs.CL

- **[Scaling Laws for Tool-Use Agents via Controllable Environment Synthesis](https://arxiv.org/abs/2610.37648)** | cs.LG | Andrew Szot, Samira Abnar
  Uses controllable synthetic environments to study how "data mix" affects tool-using agent training, yielding a predictable scaling law — directly usable by teams that want to build their own agent training data.

- **[GEPA-Curator: Curated Learning for Self Improving Agents](https://arxiv.org/abs/2610.37651)** | cs.CL | Zack Yu, Nicholas Lee
  Not every failure in multi-turn agentic tasks can be fixed by "reflection"; this work filters failure types before learning, which beats undifferentiated reflection over failed rollouts.

- **[EnvSched: Environment-Aware Scheduling for Rollout-Efficient Agent Reinforcement Learning](https://arxiv.org/abs/2610.37609)** | cs.LG | Sihan Yang, Weichen Bai
  With a limited rollout budget, it lifts data management to the "environment" level for scheduling, letting agent RL reach the same gains with fewer rollouts.

- **[MuonGS: Pretraining LLMs with Relaxed Weight-Norm Control](https://arxiv.org/abs/2610.37647)** | cs.LG | Athanasios Glentis, Dawei Li
  Systematically analyzes weight-norm control across the whole Muon run and proposes a "relaxed" variant — a rare reproducible improvement at the pretraining-recipe level.

- **[Heads of Security: Learned Attention Gates Improve Prompt Injection Robustness](https://arxiv.org/abs/2610.37657)** | cs.LG | Igor Shilov, Xiaoxue Yang
  Uses a small number of learnable per-head attention gates to force "instruction / data" separation, building prompt injection defense into the attention layers rather than bolting on an external classifier.
