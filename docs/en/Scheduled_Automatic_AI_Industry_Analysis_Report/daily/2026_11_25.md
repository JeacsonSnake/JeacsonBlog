## 📄 arXiv Papers — cs.AI / cs.LG / cs.CL
*(The 5 papers most relevant to agent / reasoning / LLM training / inference)*

- **[ToolSmith: An Automatic Tool-Generation Framework for Multimodal Search Agents](https://arxiv.org/abs/2611.31198)** | cs.CL | Rui Sun, Junhua Huang
  *Multimodal search agents currently rely on hand-built tool libraries; ToolSmith has models automatically generate missing tools per task and plug them into the retrieval pipeline, lowering tool-engineering cost.*
- **[Language Models Steer on Injected Uncertainty Tokens, but Fail to Self-Monitor In Situ](https://arxiv.org/abs/2611.31228)** | cs.AI | Daniel Theron
  *Having a model verbalize step-by-step confidence during generation does not give it true in-situ self-monitoring; models are swayed by injected uncertainty tokens.*
- **[CO-GRAFT: Attributing Reinforcement Learning Gains in Search Agents via Role-Level Policy Grafting](https://arxiv.org/abs/2611.31185)** | cs.IR | Ramraj Chandradevan, Sayontan Ghosh
  *RL can raise exact-match by up to 32 points for LLM search agents; the authors use role-level policy grafting to break down which capabilities the gains come from.*
- **[Habitats: A Framework for Open-Ended Evolution of Agent Objectives](https://arxiv.org/abs/2611.31160)** | cs.AI | Nicolas Bolouri, Gaya Mehenni
  *Proposes a framework for the open-ended evolution of agent objectives, reducing the burden of hand-designing rewards for every task.*
- **[Precision-Aware Learning Rate Transfer Across Block Count in LLM Post-Training](https://arxiv.org/abs/2611.31166)** | cs.LG | Nan Chen, Soledad Villar
  *For SFT / DPO / RLVR post-training, studies how learning rates transfer across model depth, cutting tuning cost after depth changes.*
