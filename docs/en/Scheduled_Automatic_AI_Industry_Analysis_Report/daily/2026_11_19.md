## 📄 arXiv Papers — cs.AI / cs.LG / cs.CL
*(The 5 papers most relevant to agents / reasoning / LLM training / inference)*

- **[Do LLM Agents Still Need to Be Told How to Self-Improve?](https://arxiv.org/abs/2611.23219)** | cs.LG | Shobhita Sundaram, Cansu Sancaktar
  *Give a frozen LLM agent a compute budget and tools, and let it design "how to self-improve" itself instead of following an externally preset training loop; sufficiently strong models can autonomously build self-learning algorithms, and the learned text artifacts transfer to new game mechanics and 3D navigation tasks.*
- **[Agent Trust Infrastructure (ATI): A Federated Identity, Trust, Attestation, and Accountability Architecture for Cross-Organization Autonomous AI Agents](https://arxiv.org/abs/2611.23202)** | cs.AI | Viet K. Nguyen, Mohammad I. Husain
  *Trust infrastructure for cross-organization agent collaboration: built on PKI, zero trust and remote attestation, it validates agent certificates, model/tool/system prompt configurations and authorization before execution; in an 8-organization simulated federation, attack containment rises from 43% to 84% at roughly 174 microseconds of overhead per request.*
- **[Higher-Scoring Coding Models Did Not Get More Work Done](https://arxiv.org/abs/2611.23216)** | cs.SE | Yining Hua
  *Uses the 19-day outage of Claude Fable 5 caused by US export controls on 2026-06-12 as a natural experiment, tracking 7-day PR merge rates for 297 users: after switching to a model 11 points lower, the merge rate moved only 1.4 percentage points and not significantly — benchmark scores did not convert into more real work.*
- **[Ambient LLMs: Data-Efficient Supervised Fine-tuning via Temperature Matching](https://arxiv.org/abs/2611.23229)** | cs.LG | Giannis Daras, Marios Papachristou
  *Addresses overfitting and tail forgetting when SFT data is scarce with Ambient SFT: using a frozen pretrained model as a "noise teacher" and matching a high-temperature conditional distribution; average relative gains of up to 21% on domain adaptation, instruction tuning and reasoning tasks.*
- **[Fine-Tuning Gemma 4 Edge Models for MATLAB Signal-Processing Code with SFT and QLoRA on a Laptop iGPU](https://arxiv.org/abs/2611.23205)** | cs.LG | Mehmet Altan Toksöz
  *Fine-tunes Gemma 4 E2B/E4B with LoRA / QLoRA on a laptop iGPU to generate MATLAB signal-processing code, deploying int8 models with OpenVINO; E2B pass rate rises from 18/66 to 37/66 and E4B from 32/66 to 47/66, at the cost of a 17–19% drop in generation speed.*
