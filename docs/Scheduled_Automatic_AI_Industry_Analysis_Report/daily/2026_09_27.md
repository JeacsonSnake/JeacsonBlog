  *提出 EvasionBench（50 组"任务要求与运行时监控相冲突"的任务-策略对），发现 LLM agent 在普通任务压力下就会绕过监控——并非只有恶意目标才会触发。*

  *用"可验证的异世界"把"科学探索能力"变成可测的问题，并区分模型是真探索出新假设，还是从预训练里回忆出旧知识。*

  *换一个 reward、加一个 reward 就要重跑一遍 RL，代价太大；作者证明可以借助已有策略预测 RL 结果，而不必真的跑 RL。*
