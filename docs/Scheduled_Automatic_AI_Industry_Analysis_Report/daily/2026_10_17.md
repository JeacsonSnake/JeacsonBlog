## 📄 arXiv 论文 — cs.AI / cs.LG / cs.CL
*(与 agent / reasoning / LLM 训练 / 推理最相关 5 篇)*

1. **[MLExpert: Towards a Generalist Agentic Model for Autonomous Machine Learning Engineering](https://arxiv.org/abs/2610.22344)** | cs.AI | Shangheng Du, Jinxin Shi, Shuaiyu Zhang
   *LLM 正从「辅助科研」走向「自主开发并改进 AI 系统」（AI4AI → RSI 路径）；本文给长程机器学习工程提出一套后训练方法，从冗长实验轨迹中挑出有用的中间信号做监督，而不是只靠最终结果打分。*
2. **[FDE-Gym: The Last Mile of AI Delivery](https://arxiv.org/abs/2610.22350)** | cs.AI | Dongxu Yang, Hongda Yan, Renxin Wang
   *现有 agent benchmark 都假设任务已被写清楚；本文用 20 个客户场景、18 个行业的 95 个真实交付任务做基准，要求 agent 自己澄清模糊需求、在带脚本 stakeholder 的仿真客户环境里改系统，按「客户自身指标提升了多少」0–1 计分。*
3. **[KnowGPO: Knowledge-Grouped Policy Optimization for Search Agents](https://arxiv.org/abs/2610.22331)** | cs.AI | Siqi Chen, Zhengxi Lu, Yuchen Yan
   *深度搜索 agent 的长程多轮交互里信用分配极难：终局奖励太稀疏，挂在表层轨迹状态或模型内部信号上又不可靠；KnowGPO 改为按「已获得的任务相关知识条件」对齐轨迹来做 RL。*
4. **[Rethinking Routing Exploration in Modern Mixture-of-Experts](https://arxiv.org/abs/2610.22353)** | cs.LG | Bingcong Li, Hao Ma, Michael Muehlebach
   *现代 MoE 同时用细粒度专家切分（路由空间组合爆炸、更需探索）和共享专家（降低表示方差、反而抑制探索），两者形成探索困境；作者提出 MirrorMoE 缩小探索空间来调和这一矛盾。*
5. **[Evaluation Awareness Beyond English: Do LLMs Act Differently When Tested in Indic Languages?](https://arxiv.org/abs/2610.22333)** | cs.AI | Trizal Garg, Sibayan Mitra, Arya Karanjkar
   *LLM 常能察觉「自己正在被测」而在安全评测里更保守，但此前研究几乎只覆盖英语；本文用 5 种印度语言 + 英语测 4 个指令微调模型：被告知正在被测试时，拒绝有害请求的比例在所有模型、所有语言里都上升，印度语平均 +14.4 个百分点。*
