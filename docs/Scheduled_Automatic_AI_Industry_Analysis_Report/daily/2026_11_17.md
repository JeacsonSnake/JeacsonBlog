## 📄 arXiv 论文 — cs.AI / cs.LG / cs.CL

- **[ModHarness-RL: Recasting Harnesses as Learnable and Evolving Programs for Agentic RL](https://arxiv.org/abs/2611.18533)** | cs.AI | Zelin He, Siyu Zhu
  *把 agentic RL 里手写的 harness 改成"可学习、随训练演化的程序"：用结构化的 State 记录交互，Compression 程序决定上下文怎么拼、Steering 程序在行为跑偏时给引导。候选程序由近期轨迹提出、执行验证后回放，在 CodeSearch、ALFWorld、BIRD SQL 上验证。*
- **[Can Mechanistic Interpretability Help Explain LLM Agent Failures? A Case Study on Web Element Hallucination](https://arxiv.org/abs/2611.18514)** | cs.AI | Mohamed Aghzal, Mor Geva
  *用 Qwen2.5-7B 在真实网站上做机制可解释性实验：末位 token 的线性探针能在生成前预测"幻觉出不存在的网页元素"（0.80 AUC），沿探针方向 steer 能纠正 85% 的幻觉。但探针方向对 prompt 格式极其敏感，动作表示稍作改动效果就大幅衰减——MI 目前只能部分解释 agent 失败。*
- **[Training Reasoning Models in Simulation to Natively Use Real Robots](https://arxiv.org/abs/2611.18562)** | cs.RO | Jiaming Tang, Zhuoyang Zhang
  *在纯仿真、无示教数据的情况下用 RL 训练一个开源 27B 推理模型原生操作真机，思路照搬 computer-use agent：观察环境→思维链→直接输出末端位姿，不要 harness。仿真学到的技能可迁移到未见过的机器人、真实世界和新指令。*
- **[WeightBench: Evaluating Language Models as Weight-Space Programmers](https://arxiv.org/abs/2611.18553)** | cs.LG | Aayush Marasini, Barsat Khadka
  *系统评测"直接改神经网络权重"这一新范式：42 个任务分读权重、修权重、写权重、识别不可能编辑、无数据压缩五条赛道，网络规模从 2K 参数控制策略到 7B 语言模型。前沿 agent 已能读懂小网络并写出可用的控制策略，但还补不了语言模型的权重、也分不清"难"和"不可能"。*
- **[Do Verifier Judgments Survive Abstraction? Measuring Verification Transport for LLM Agent Evaluation](https://arxiv.org/abs/2611.18471)** | cs.CL | Disha Sheshanarayana, Sai Linisha Reddy Goli
  *指出 LLM verifier 的可靠性只在单一轨迹表示下被测过：一旦经过工具组合、委派边界、历史压缩，同一段执行暴露给 verifier 的证据就变了。作者提出 Verification Transport 测试，在四个基准上测得抽象导致的判断失稳最高约 31%。*
