- **[Legibility is Not Interpretability: Comparing Judged and Actual Importance in Chain-Of-Thought Reasoning](https://arxiv.org/abs/2609.04194)** | cs.CL | Kevin Du, Alexander Hoyle
  *对比 CoT 推理链中被"判定重要"与实际重要的 token，论证推理链的可读性（legibility）并不等于可解释性（interpretability），可读外观反而会误导归因。*

  *对软件工程 agent 的评估提出质疑：通过功能测试≠任务真正完成，给出超越函数级测试的新评测框架，直击 coding agent 基准设计的盲区。*
