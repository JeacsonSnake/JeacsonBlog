📄 arXiv Papers — cs.AI / cs.LG / cs.CL

  • ModHarness-RL: Recasting Harnesses as Learnable and Evolving Programs for Agentic RL | cs.AI | Zelin He, Siyu Zhu Recasts the hand-written harness in agentic RL as "a learnable program that evolves with training": structured State records the interaction, a Compression program decides how context is assembled, and a Steering program offers guidance when behavior drifts. Candidate programs are proposed from recent trajectories, verified by execution, then replayed; validated on CodeSearch, ALFWorld and BIRD SQL.
  • Can Mechanistic Interpretability Help Explain LLM Agent Failures? A Case Study on Web Element Hallucination | cs.AI | Mohamed Aghzal, Mor Geva Mechanistic interpretability experiments with Qwen2.5-7B on real websites: a linear probe on the last token can predict, before generation, that the model will "hallucinate a non-existent web element" (0.80 AUC), and steering along the probe direction corrects 85% of the hallucinations. But the probe direction is extremely sensitive to prompt format — a small change in how actions are represented sharply degrades the effect — so MI can currently explain agent failures only partially.
  • Training Reasoning Models in Simulation to Natively Use Real Robots | cs.RO | Jiaming Tang, Zhuoyang Zhang Using RL in pure simulation, with no demonstration data, to train an open 27B reasoning model to natively operate a real robot — copying the computer-use agent recipe: observe the environment → chain of thought → output the end-effector pose directly, no harness. Skills learned in simulation transfer to unseen robots, the real world and new instructions.
  • WeightBench: Evaluating Language Models as Weight-Space Programmers | cs.LG | Aayush Marasini, Barsat Khadka Systematically evaluates the new paradigm of "editing neural network weights directly": 42 tasks across five tracks — reading weights, editing weights, writing weights, identifying impossible edits, and data-free compression — with network sizes from 2K-parameter control policies up to 7B language models. Frontier agents can already read small networks and write usable control policies, but they still cannot patch the weights of language models, nor tell "hard" from "impossible".
  • Do Verifier Judgments Survive Abstraction? Measuring Verification Transport for LLM Agent Evaluation | cs.CL | Disha Sheshanarayana, Sai Linisha Reddy Goli Points out that LLM verifier reliability has only been measured under a single trajectory representation: once tool composition, delegation boundaries and history compression intervene, the evidence the same execution exposes to the verifier changes. The authors propose the Verification Transport test and measure, across four benchmarks, judgment instability of up to roughly 31% caused by abstraction.
